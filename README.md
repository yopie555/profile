## 🚀 How to Run Locally

You can open the website in any modern web browser directly:

### Option 1: Direct File Open
Double-click or open `index.html` in your favorite web browser:
- Google Chrome
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

### Option 2: Local HTTP Server (Python / Node)
Using Python 3:
```bash
cd yopy-personal-website
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

Using Node `npx serve`:
```bash
cd yopy-personal-website
npx serve .
```
